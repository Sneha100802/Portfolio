Use one persistent desktop renderer with distance-based exhibit visibility and viewport-scaled parallax. The mobile renderer presents only the hero and the HTML continues vertically. The HTML also serves reduced-motion and renderer-failure paths.

Assets include locally installed Inter and Cormorant Garamond, existing Simple Icons paths, and the locally bundled Poly Haven studio HDRI. Exhibit geometry is procedural. The social preview comes from the rendered gallery.

The reference sites inform pacing, composition and lighting. No reference assets or layouts enter the project. Review the output at 1920×1080, 1440×900, 1280×720 and 390×844.
