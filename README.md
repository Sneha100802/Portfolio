# Sneha Jha — Interactive Portfolio

An interactive, storybook-inspired portfolio showcasing my journey in software development, artificial intelligence, data science, and creative technology.

Designed as a digital watercolor book, this portfolio combines personal storytelling, artistic illustrations, and interactive navigation to create a memorable experience.

## About the Portfolio

This portfolio presents my professional journey through an immersive book-inspired interface. Instead of a conventional portfolio layout, visitors can explore different chapters of my education, experience, projects, and technical skills.

## Features

* **Interactive Storybook Design:** A book-inspired interface with an immersive browsing experience.
* **Watercolor Illustrations:** Artistic visuals inspired by traditional Indian aesthetics and storytelling.
* **Personal Introduction:** A dedicated section introducing my background and interests.
* **Professional Journey:** Explore my education, internships, and professional experience.
* **Project Showcase:** Detailed presentations of my AI, machine learning, and software development projects.
* **Technical Skills:** Overview of my programming languages, frameworks, and tools.
* **Publications:** Academic research and publications.
* **Contact Section:** Connect with me for professional opportunities and collaboration.
* **Responsive Design:** Designed to provide a smooth experience across different screen sizes.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Sneha100802/Portfolio.git
```

### Navigate to the Project

```bash
cd Portfolio
```

### Run Locally

If the project uses plain HTML, CSS, and JavaScript, open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code for local development.

## Deployment

This portfolio is hosted using **GitHub Pages**.

The website is deployed from the repository's configured production branch.

Whenever updated code is pushed to the deployment branch, GitHub Pages automatically builds and publishes the changes.
